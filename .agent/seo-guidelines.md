## SEO Rules

### Keyword usage:

| Do                                            | Do not                                                 |
| --------------------------------------------- | ------------------------------------------------------ |
| Use keywords naturally in sentences           | Force exact-match phrases repeatedly                   |
| Write for humans first, search engines second | Write for search engines at the expense of readability |
| Use semantic variations                       | Repeat the same phrase mechanically                    |
| Prefer entity/topic relevance over repetition | Keyword-stuff visible copy                             |

### Example:

**Good:**

> "The Tooth Dental Studio provides dental care in Tolichowki, Hyderabad. Dr. Mohammed Imran Ali focuses on patient comfort and clear communication."

**Bad:**

> "The Tooth Dental Studio is the best dental clinic in Tolichowki Hyderabad. If you need a dental clinic in Tolichowki Hyderabad, visit our dental clinic in Tolichowki Hyderabad."

### Exact phrase to avoid overusing:

Do not force the exact phrase "best dental clinic in Tolichowki Hyderabad" everywhere.

This phrase:

- Is not approved in the content foundation
- Sounds unnatural when repeated
- May trigger spam filters
- Does not match the brand voice

Instead, establish relevance through natural language and semantic relationships.

### Image SEO:

| Element   | Approach                                     |
| --------- | -------------------------------------------- |
| Filenames | Use descriptive filenames (already in place) |
| Alt text  | Describe the actual image content            |
| Context   | Connect image to page topic naturally        |

### Alt text guidelines:

**Good alt text:**

- Describes what's actually in the image
- Is specific and accurate
- May include relevant context (clinic name, location) where appropriate
- Is concise but meaningful

**Example:**

| Image             | Alt text                                                                           |
| ----------------- | ---------------------------------------------------------------------------------- |
| Doctor portrait   | "Dr. Mohammed Imran Ali, General Dentist at The Tooth Dental Studio in Tolichowki" |
| Clinic front desk | "Reception area at The Tooth Dental Studio, Tolichowki, Hyderabad"                 |
| Treatment image   | "Dental treatment in progress at The Tooth Dental Studio"                          |
| Before/after      | "Dental treatment case from The Tooth Dental Studio"                               |

### Heading hierarchy:

```
H1: One per page, primary topic/brand statement
  H2: Major section headings
    H3: Subsection headings
      H4: Sub-subsection if needed
```

| Rule                                     | Reason                              |
| ---------------------------------------- | ----------------------------------- |
| Use exactly one H1 per page              | Clear primary topic signal          |
| H1 should include brand or primary topic | Establish entity                    |
| H2s should organize major sections       | Create content structure            |
| Maintain logical hierarchy               | Semantic clarity for search engines |
| Do not skip heading levels               | Proper document structure           |

## Medical SEO Safety

### Do not create unsupported claims:

| Claim type                   | Why avoid                                 |
| ---------------------------- | ----------------------------------------- |
| Guaranteed clinical outcomes | Cannot be guaranteed; may be misleading   |
| Treatment superiority claims | Must be supported by evidence             |
| "Best dentist" claims        | Often legally restricted; unsubstantiated |
| Credential claims            | Must be verified and accurate             |
| Diagnosis claims             | Must be made by qualified professionals   |

### Safe language patterns:

| Instead of                      | Use                                                    |
| ------------------------------- | ------------------------------------------------------ |
| "Best dentist in Hyderabad"     | "Patient-focused dental care in Tolichowki, Hyderabad" |
| "Painless treatment guaranteed" | "Comfortable treatment experience"                     |
| "100% success rate"             | "Treatment tailored to your individual needs"          |
| "We are the top dental clinic"  | "5.0-star Google rating with 1,147 reviews"            |

### Medical content rules:

- All medical/treatment content must reference approved content from CANONICAL.md
- Do not invent medical claims or statistics
- Use careful, honest language about treatments
- When in doubt, be conservative rather than exaggerated
